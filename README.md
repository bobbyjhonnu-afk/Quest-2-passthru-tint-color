# Quest-2-passthru-tint-color
Meant for quest 1 (Monotry) but this was a suggestion for Singleluarity
Magisk module that allows you to apply a custom tint and strength to the passthrough system-wide, works in all apps that use passthrough APIs. Defaults to a cyan blue, and can be customized in tint.conf in the zip prior to install, or by running ptcolor as root.
